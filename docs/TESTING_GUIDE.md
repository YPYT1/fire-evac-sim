## 🐛 已知问题与预期行为

### 启动时间
- **一楼**：通常 2-3 秒
- **二楼**：可能需要 5-10 秒（正常）⏳
- **三楼**：可能需要 10-15 秒（正常）⏳

### 为什么二三楼慢？
```
原因：
1. 需要加载更复杂的楼层结构
2. 需要计算更多的路径网格
3. 需要初始化多层楼梯连接
4. 后端需要生成多层火点和出口

这是后端计算密集型操作，前端已添加加载提示改善体验
```

### 材质透明度问题
- 透明墙壁后面的物体可能出现渲染顺序问题（Three.js 透明度限制）
- 这是图形渲染的正常现象，不影响仿真功能

## 🚀 如果遇到问题

### 问题 1：楼层切换无效果
```bash
# 解决方案：
1. 清除浏览器缓存（Ctrl+Shift+R）
2. 重启前端服务：pnpm dev
3. 检查控制台是否有 Three.js 错误
```

### 问题 2：启动超过 30 秒无响应
```bash
# 解决方案：
1. 检查后端日志：tail -f logs/backend.log
2. 检查后端是否正常运行
3. 重启后端：./start_macos.sh
```

### 问题 3：火点不显示
```bash
# 解决方案：
1. 检查是否已连接 WebSocket
2. 查看控制台网络面板
3. 确认 VITE_BACKEND_URL 配置正确
```
