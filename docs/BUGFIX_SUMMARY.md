## 🐛 修复的问题

### 问题 1: 二楼地板显示异常 ✅

**问题描述：**
- 选择二楼着火点时，二楼的地板也被隐藏了
- 用户无法看到二楼的完整结构

**根本原因：**
原逻辑只判断 Y 坐标，没有识别地板/楼顶元素，导致二楼地板（Y≈4）被误判为一楼墙壁而透明化

**修复方案：**
```typescript
// 新增地板判断逻辑
const isFloor = meshName.includes('floor') || 
                meshName.includes('ceiling') || 
                (Math.abs(y - 4) < 0.5) ||  // 二楼地板
                (Math.abs(y - 8) < 0.5);    // 三楼地板

// 二楼模式：排除地板，只让墙壁透明
else if (y < 4.5 && y > 0.1 && !isFloor) {
  // 一楼墙壁透明（但不包括地板）
  child.material.opacity = 0.25;
}
```

**修复效果：**
| 模式 | 一楼地板 | 二楼地板 | 三楼地板 |
|------|---------|---------|---------|
| 一楼 | ✅ 显示 | ❌ 隐藏 | ❌ 隐藏 |
| 二楼 | ✅ 显示 | ✅ 显示 | ❌ 隐藏 |
| 三楼 | ✅ 显示 | ✅ 显示 | ✅ 显示 |

### 问题 2: 一楼模式应隐藏二楼地板 ✅

**问题描述：**
- 选择一楼着火点时，二楼的地板（即一楼的楼顶）应该隐藏
- 目前显示了二楼地板，影响一楼视角

**修复方案：**
```typescript
if (mode === 'floor1') {
  // 隐藏二楼地板（一楼楼顶）
  if (isFloor && y > 3.5 && y < 4.5) {
    child.visible = false;
  }
}
```

**修复效果：**
- ✅ 一楼模式看不到天花板
- ✅ 视野更开阔
- ✅ 符合用户预期

### 问题 3: 切换模式时旧火点残留 ✅

**问题描述：**
- 从三楼切换到二楼后，三楼的火点仍然显示
- 新旧火点混在一起，造成混淆

**根本原因：**
启动新仿真前没有清除旧数据，store 中保留了上一次的 fires 数组

**修复方案：**
```typescript
async function onStart() {
  // 🔥 关键修复：启动前清除所有旧数据
  store.reset();
  
  // 然后再启动新仿真
  const response = await startSimulation({ ... });
}
```

**修复效果：**
- ✅ 切换模式立即清空旧火点
- ✅ 只显示新模式的火点
- ✅ 数据不混乱

---

### 问题 4: 停止仿真后状态未重置 ✅

**问题描述：**
- 点击"停止仿真"后，火点、路径等仍然显示
- 场景没有恢复到初始状态

**修复方案：**
```typescript
async function onStop() {
  await stopSimulation(store.sessionId);
  socket?.close();
  socket = null;
  
  // ✅ 重置所有状态
  store.reset();
  
  // ✅ 显示停止提示
  showToastNotification('仿真已停止', 'info');
}
```

**修复效果：**
- ✅ 停止后火点消失
- ✅ 停止后路径消失
- ✅ 停止后统计数据归零
- ✅ 用户收到停止确认提示

---

### 问题 5: 模式切换不生效 ✅

**问题描述：**
- 切换楼层模式（一楼/二楼/三楼）后，场景没有变化
- 需要刷新页面才能看到效果

**根本原因：**
Vue watch 的 `immediate: false` 导致初始加载时不应用默认视角

**修复方案：**
```typescript
watch(
  () => store.mode,
  (mode) => {
    updateFloorVisibility(mode);
    adjustCameraForFloor(mode);
  },
  { immediate: true }  // ✅ 改为 true，立即生效
);
```

**修复效果：**
- ✅ 页面加载时应用默认视角
- ✅ 切换模式立即更新场景
- ✅ 无需刷新页面

## 🔧 技术细节

### 地板识别算法

```typescript
/**
 * 判断网格对象是否为地板/楼顶
 * 
 * 方法1: 名称匹配（最可靠）
 * - 包含 'floor' 或 'ceiling' 关键字
 * 
 * 方法2: 位置判断（兜底）
 * - Y ≈ 4 (±0.5) → 二楼地板
 * - Y ≈ 8 (±0.5) → 三楼地板
 */
const isFloor = meshName.includes('floor') || 
                meshName.includes('ceiling') || 
                (Math.abs(y - 4) < 0.5) || 
                (Math.abs(y - 8) < 0.5);
```

### 透明度分级

```typescript
// 墙壁透明度：25%（更清晰）
child.material.opacity = 0.25;

// 理由：
// - 0.15 太透明，看不清结构
// - 0.25 正好，既能看清下层，又保持可见性
```

### 数据清除时机

```typescript
// ⏱️ 时机1：启动新仿真前
store.reset();  // 清除旧的火点、路径、统计

// ⏱️ 时机2：停止仿真后
store.reset();  // 恢复初始状态
```
