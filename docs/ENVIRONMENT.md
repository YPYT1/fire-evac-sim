# 开发环境确认

本项目开发需满足以下工具及版本要求，并已针对当前环境进行确认：

| 工具 | 版本要求 | 当前状态 |
|------|----------|----------|
| Python | 3.11.x | 待开发者安装或使用 uv 下载（后续 `uv python pin 3.11`）。 |
| uv | ≥0.8.11 | 将随 `uv` 初始化流程安装与配置。 |
| Bun | ≥1.2.23 | 可通过 `curl -fsSL https://bun.sh/install | bash` 安装；尚需根据本地环境确认。 |
| Node.js 生态依赖 | 与 Bun 兼容 | 使用 Bun 自动管理。 |
| Three.js 工具链 | 最新稳定版 | 在前端初始化阶段通过 Bun 安装。 |
| Git | 2.x+ | 当前仓库已存在 `.git/`。 |

> 提示：如需验证工具是否已安装，请分别运行 `python3 --version`、`uv --version`、`bun --version` 等命令。若版本不符合，按照 README 中的安装指引升级。

后续阶段将在完成依赖初始化后更新本表状态。
