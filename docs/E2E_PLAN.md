# 前端 E2E 测试计划

## 目标
- 验证前后端集成后的主要用户流程（启动仿真、观察可视化、手动添加火点）。
- 保障 Three.js 场景渲染、WebSocket 数据联动与控制面板交互的稳定性。

## 工具建议
- **Playwright**（首选）：内置 WebSocket 与截图支持，便于三维场景比对。
- **Cypress**（备选）：生态成熟，团队已有使用经验时可选。

## 场景用例
1. **基础启动流程**
   - 访问首页 → 启动 fixed 模式 → 验证状态面板人数更新。
2. **手动火点**
   - 启动 manual 模式 → 点击画布放置火点 → 验证火点列表与状态更新。
3. **重启/停止**
   - 停止仿真 → 再次启动 → 确认没有残留状态。

## 实施时间
- 建议在阶段 3 联调完成后，接入 Playwright 测试脚手架，并复用 Vitest 配置中的别名。
